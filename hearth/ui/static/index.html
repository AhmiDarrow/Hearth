Settings

General

Adds or removes a shortcut in your Startup folder. Hearth never writes a Registry Run key.

System follows your Windows light or dark mode. Optional palettes are below.

Sharing

Folders this PC is sharing with the house. Read-only lets others browse and download; read & write also lets them add files.

Files you download from other PCs are saved here. Defaults to your Downloads folder.

Network

Sub-routers hide UDP broadcasts. Add the other PC's IP to join across subnets, or turn on Bridge on a machine that can see both networks.

Peer HTTP uses TCP 7474. Discovery uses UDP 45454.

Help

Start a home group on one PC, then copy the invite from Settings → Network and paste it on the others. Share a folder from the toolbar, or drag a folder onto “Shared from this PC”. Open a folder by double-clicking it. Download a file with Download, or drag it out of Hearth onto your desktop. Right-click a file for more actions. The menu in the title bar (or the gear) always opens Settings, even before you join a group.
